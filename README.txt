 עדכון — תפריט צד ראשי + קיצור דרך לחובות + מסך תובנות והערות
============================================================

קבצים בזיפ:
1. index.html   — שונה
2. style.css    — שונה (עודכן, אין צורך לגעת — רק תחליף)
3. script.js    — ללא שינוי (מוחלף רק ליישור גרסאות, לא חובה)
4. debts.js     — ללא שינוי בלוגיקה (זהה לגרסה הקודמת)
5. notes.js     — קובץ חדש! (מסך "תובנות והערות אישיות")
6. sidemenu.js  — קובץ חדש! (לוגיקת התפריט הנפתח מימין)

קבצים שלא נכללים כאן ואינם צריכים שינוי:
patch.js, glide.js, pension-profile-fix.js, dashboard-v8.js,
dashboard-upgrade.css, service-worker.js, manifest.json

============================================================
התקנה (מהאייפון, ב-GitHub — עריכת קבצים בדפדפן / האפליקציה)
============================================================
1. העלה/החלף בריפו את הקבצים הבאים באותם שמות בדיוק:
   - index.html   (החלפה)
   - style.css    (החלפה)
   - debts.js     (החלפה - זהה בפועל, אפשר לדלג אם לא נוח)
2. הוסף שני קבצים חדשים לתיקיית הפרויקט (לצד script.js):
   - notes.js
   - sidemenu.js
3. אין צורך לגעת בשאר הקבצים.
4. מומלץ לעדכן את מספר הגרסה ב-service-worker.js (משתנה
   CACHE_NAME, למשל ל-v42) כדי לוודא שהמכשירים יטענו את
   הגרסה החדשה מיד ולא ישתמשו בעותק שמור מהמטמון.

============================================================
מה נוסף / השתנה
============================================================

1. קיצור דרך "החובות שלנו" בדף הבית
   -----------------------------------------------------
   נוסף כרטיס קיצור-דרך מרכזי חדש בראש דף הבית (לצד "הון
   נזיל" ו"שווי נקי"), שמציג את סך יתרת ההלוואות ומספר
   ההלוואות הפעילות, ומוביל ישירות לטאב "החובות שלנו"
   בלחיצה.

2. תפריט צד (נפתח מימין)
   -----------------------------------------------------
   נוסף כפתור המבורגר (☰) בפינה העליונה של דף הבית, לצד
   כפתור הפרופיל. לחיצה עליו פותחת תפריט הנשלף מצד ימין
   עם 11 הפריטים הבאים, לפי הסדר שנקבע:

     1. פרופיל משפחתי                → מסך פרופיל
     2. תיק הנכסים שלנו               → מסך השקעות
     3. הפרישה שלנו                   → סימולטור פנסיה
     4. החלומות והיעדים שלנו          → מסך יעדים
     5. העתיד שלנו                    → מסך סיכום ועלויות
     6. החובות שלנו                   → מסך חובות
     7. הפק דו״ח מסכם                 → מריץ את פונקציית
                                          הדו״ח הקיימת
                                          (generateReport),
                                          במקום הכפתור
                                          שהיה מתחת לקיצורי
                                          הדרך המרכזיים —
                                          כפתור זה הוסר
                                          מדף הבית.
     8. מפת דרכים                     → מסך מפת דרכים
     9. גרפים                         → מסך גרפים
    10. תזרים חודשי                   → placeholder בלבד;
                                          לחיצה מציגה הודעת
                                          "בקרוב" ואינה
                                          פותחת מסך (עדיין
                                          לא מומש).
    11. תובנות והערות אישיות          → מסך חדש (ראה סעיף 3)

   בתחתית התפריט נשאר כפתור קבוע "🏠 חזרה לדף הבית".
   כמו כן נשמר כפתור החזרה לדף הבית הקיים (העיגול הכחול
   הצף בפינה, home-fab) בכל מסך מודול — לא הוסר.

   רשת קיצורי-הדרך הישנה בתחתית דף הבית (10 הכרטיסים
   הגדולים) הוסרה והוחלפה בכרטיס קריאה-לפעולה יחיד
   שפותח את התפריט החדש.

   שימו לב: הגישה למסך "פרופיל משפחתי" עדיין קיימת גם
   משני הכפתורים הקיימים בראש דף הבית (כפתור הפרופיל
   ליד ההמבורגר, וכרטיס "שווי נקי מומלץ" כאשר הוא גלוי) —
   בהתאם למה שביקשת, ניתן (לא חובה) להסיר אותם בהמשך אם
   תרצה שהגישה תהיה רק דרך התפריט.

   הטאבים "המלצות ואסטרטגיה" (strategy) ו"צמיחה ותחזיות"
   (projections) לא נכללו ברשימת 11 הפריטים שסיפקת, ולכן
   לא נוספו לתפריט. הם עדיין נגישים כרגיל דרך שני קיצורי
   הדרך המרכזיים הקיימים בראש דף הבית (כרטיס "שווי נקי"
   מוביל לצמיחה ותחזיות, וכרטיס התובנה האסטרטגית המותנית
   מוביל להמלצות ואסטרטגיה). אם תרצה שגם הם יופיעו בתפריט
   הצד, אפשר להוסיף בקלות.

3. מסך חדש: "תובנות והערות אישיות"
   -----------------------------------------------------
   מסך חדש לגמרי (notes.js), הכולל:
   • תיבת טקסט לכתיבת הערה/תובנה חופשית.
   • שמירה לרשימה מתמשכת (plan.notes[]), עם תיעוד תאריך
     ושעה מדויקים של מועד הכתיבה.
   • כל הערה קיימת ניתנת לעריכה (מתעד גם "נערך" + תאריך
     עדכון) ולמחיקה.
   • ההערות מוצגות מהחדשה לישנה.
   • הנתונים נשמרים בתוך התוכנית הפעילה (כמו כל שאר
     הנתונים באפליקציה) ומסתנכרנים/מיוצאים באותו אופן.

============================================================
הערות טכניות
============================================================
• כל השינויים בלוגיקה נעשו בקבצים נפרדים (notes.js,
  sidemenu.js) ולא בתוך script.js הליבה, בהתאם לארכיטקטורה
  הקיימת (patch.js, glide.js וכו').
• עברו בדיקת תחביר (node --check) לכל קובצי JS החדשים.
• לא נמצאו התנגשויות ב-id בין index.html לקבצי ה-JS.
• עוצב בהתאם לשפת העיצוב הקיימת (Heebo, --brand-primary
  וכו') כך שהתפריט והכרטיס החדשים ייראו חלק מהמערכת.
